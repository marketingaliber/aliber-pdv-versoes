# Aliber PDV — versões

Instaladores do **Aliber PDV**, o PDV da Aliber Informática / Sistemas.

- **Instalação nova:** baixe o `AliberPDV-Setup.exe` da [versão mais recente](https://github.com/marketingaliber/aliber-pdv-versoes/releases/latest).
- **Atualização:** no Aliber PDV, *Configurações > Versão do sistema* (área do técnico, com senha).
  Quem está na 0.3.0 instala uma vez a 0.4.0 pelo Setup; dali em diante a troca é pelo próprio sistema.

Suporte: Aliber Informática / Sistemas.
